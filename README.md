# Sales Performance Dashboard

This is a Power BI dashboard I built to analyze sales data from a fictional US e-commerce company. The dataset includes over 9,000 orders across different regions, categories, and customer segments.

## What's inside

The dashboard has 5 pages:
- Executive Summary — overview of the most important numbers
- Sales Overview — monthly and yearly sales trends
- Product Performance — best and worst selling products
- Regional Analysis — sales breakdown by state and region
- Customer Insights — analysis by customer segment

## Key metrics tracked
- Total Revenue
- Total Profit
- Number of Orders
- Average Order Value
- Profit Margin

## Tools used
- Power BI Service
- Sample Superstore dataset (Kaggle)
